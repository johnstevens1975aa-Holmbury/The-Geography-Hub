Map Skills

Grid references, scale, symbols, direction and contours.

Core explanation

A strong answer defines the key concept, applies the skill, uses an example, and explains why the reasoning is accurate.

Glossary with definitions and examples

scale
The relationship between map distance and real distance.
Example: 1 cm may represent 1 km.
grid reference
A map location using numbers.
Example: A six-figure grid reference gives a precise square.
contour
A line joining equal height.
Example: Close contours show a steep slope.

Water and Carbon Cycles

Systems, stores, flows, feedback and human impacts.

Core explanation

A strong answer defines the key concept, applies the skill, uses an example, and explains why the reasoning is accurate.

Glossary with definitions and examples

store
Where material or energy is held.
Example: Ocean water is a store.
flow
Movement between stores.
Example: Evaporation is a flow.
feedback
A process that changes the original change.
Example: Ice melt can increase warming through feedback.
